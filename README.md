# OOP Battle Simulator

Welcome to the Battle Arena!

This Python project will grow into a turn-based battle between a Hero and a collection of enemies. Throughout the project, you will use GitHub to track your work and manage the game through its development lifecycle.

## Getting Started

1. Fork this repository to your GitHub account.
2. Clone your fork using GitHub Desktop.
3. Open the project in VS Code.
4. Run the game:

```bash
python game.py
```

You should see a Goblin enter the arena—but there is no Hero yet.

## Current Project Files

```text
game.py      Opens the arena and introduces the first Goblin
goblin.py    Contains the completed Goblin class
hero.py      Reserved for the future Hero class
image.png    Project banner
```

## Your First Change

Customize something small in `game.py`, such as:

* The arena name
* The Goblin’s name
* One of the introduction messages

Run the program again to verify your change. Then commit and push it to your GitHub repository.

This project is only getting started. Its documentation will grow along with the game.
